# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog
- github.blog/changelog

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent stories worth watching

- **Copilot code review adds resolution reasons** — Copilot now explains why it
  resolved a review comment, making AI code review feedback easier to act on.
  (Source: GitHub Changelog)
- **Better label management for issues is generally available** — archive
  unused labels instead of deleting them, keeping issue history intact.
  (Source: GitHub Changelog)
- **GitHub Copilot app for Beginners series** — a short how-to series covering
  writing your first prompt, managing work, and automating Dependabot PR
  triage from the Copilot app. Good starting point for developers new to
  Copilot. (Source: GitHub Blog)
- **Global model policy is generally available** — admins can now set org-wide
  policies for which AI models are allowed, simplifying Copilot governance.
  (Source: GitHub Changelog)
- **Learn agentic workflows on Awesome Copilot** — the Awesome Copilot
  learning hub has a guide to what agentic workflows are, how to install and
  run community workflows, and how to contribute your own. (Source: Awesome
  Copilot)
